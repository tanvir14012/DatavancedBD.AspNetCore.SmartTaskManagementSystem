# Build a NestJS PostgreSQL backend from scratch on Windows

I construct this backend manually, starting with an empty directory and finishing with a
working HTTP API, migrations, local administrator enrollment, security tests and a container
image. Every numbered step contains executable PowerShell and complete authored file content.
Run steps in order; do not paste Markdown fences into PowerShell.

**Scope confirmed:** this guide uses PostgreSQL and leaves all existing repository code
unchanged. The existing `NestJs` implementation is a SQL Server migration with broader
contracts. This is a complete, separate reference backend, not a PostgreSQL rewrite of those
files and not a claim of feature parity. It implements catalog-backed tenant isolation,
authentication, owner-authorized project/task CRUD, pagination, optimistic concurrency,
health probes, administrator seeding and real PostgreSQL acceptance tests. The architecture
decision created below records the boundaries and excluded legacy capabilities.

**Prerequisites:** Windows 11, PowerShell 5.1 or 7, Node.js 24 LTS or a newer supported LTS,
npm, Git, Docker Desktop running Linux containers, internet access for package/image pulls,
and unused loopback ports 55439 and 3102. No host PostgreSQL installation, global Nest CLI,
.NET SDK or pre-existing Nest source is required. Node 24 is within the requested v20+
range and matches the inspected Nest toolchain. Commands target the new folder under your
Windows user profile, never the existing repository's databases.

**Reading the architecture:** domain owns state rules and response contracts; application
owns use-case contracts; infrastructure implements persistence; feature modules compose
providers; HTTP parses and dispatches. Catalog authorization and resource ownership are
separate checks. The API cannot provision schemas. Local setup uses two tenant databases
with deliberately colliding IDs so the isolation tests can detect accidental cross-routing.

**Execution convention:** keep the first PowerShell terminal open so `Invoke-Checked`,
`Write-Source` and the working directory remain available. Only the marked smoke-test step
uses a second terminal. Single-quoted here-strings preserve TypeScript template literals,
SQL and JSON verbatim. The writer emits UTF-8 without BOM and LF line endings on either
PowerShell edition. Compiler/Prisma/npm outputs are generated by explicit commands.

## Step 1: Establish a clean PowerShell workspace

- **Goal**: I isolate the PostgreSQL build from the existing SQL Server implementation before creating any files.
- **Command / Action**:

```powershell
$ErrorActionPreference = 'Stop'
Set-StrictMode -Version Latest
$guideRoot = Join-Path $env:USERPROFILE 'source\stms-nest-postgres'
if ((Test-Path -LiteralPath $guideRoot) -and @(Get-ChildItem -LiteralPath $guideRoot -Force).Count -gt 0) { throw 'Choose a new empty guideRoot; do not overwrite a project.' }
New-Item -ItemType Directory -Path $guideRoot -Force | Out-Null
Set-Location -LiteralPath $guideRoot
function Invoke-Checked {
    param([string]$Program, [string[]]$Arguments)
    & $Program @Arguments
    if ($LASTEXITCODE -ne 0) { throw "$Program failed with exit code $LASTEXITCODE." }
}
function Write-Source {
    param([string]$Path, [string]$Content)
    $absolute = Join-Path (Get-Location).Path $Path
    $normalized = $Content.Replace("`r`n", "`n").TrimEnd() + "`n"
    [IO.File]::WriteAllText($absolute, $normalized, [Text.UTF8Encoding]::new($false))
}
Invoke-Checked node @('--version')
$major = [int]((& node -p 'parseInt(process.versions.node)') | Select-Object -Last 1)
if ($major -lt 24) { throw 'Install Node.js 24 LTS or a newer supported LTS, reopen PowerShell, then resume.' }
Invoke-Checked npm.cmd @('--version')
Invoke-Checked docker @('version')
Invoke-Checked docker @('compose', 'version')
Invoke-Checked docker @('info', '--format', '{{.OSType}}')
foreach ($name in @('NODE_ENV', 'PORT', 'HOST', 'TENANT_REGION', 'ALLOWED_ORIGINS', 'CATALOG_DATABASE_URL', 'TENANT_DATABASE_URL', 'TENANT_TARGETS', 'ADMIN_TARGETS', 'DEMO_PASSWORD', 'POSTGRES_PASSWORD')) {
    if (Test-Path -LiteralPath "Env:$name") { throw "Use a clean shell without inherited $name; Node environment files do not override process variables." }
}
```

Use Windows PowerShell 5.1 or PowerShell 7 in one terminal throughout. Start Docker Desktop in Linux-container mode first. Install Node.js from [the official downloads](https://nodejs.org/en/download) if the version check fails. Node 24 satisfies the requested v20+ baseline; this guide deliberately does not target the now-obsolete Node 20 release line. The UTF-8 writer avoids Windows PowerShell 5.1 BOM/UTF-16 defaults. `npm.cmd` avoids npm.ps1 execution-policy problems. Every native command checks its exit code; no global execution-policy changes are needed.

## Step 9: Record the storage and authorization boundary

- **Goal**: I document the independent PostgreSQL design before introducing its databases.
- **Command / Action**:

```powershell
New-Item -ItemType Directory -Path 'docs/adr' -Force | Out-Null
Write-Source 'docs/adr/0001-postgres-reference.md' @'
# PostgreSQL reference backend

Status: accepted for this standalone guide; no existing deployment is migrated.

## Context
The parent repository uses SQL Server and supports Database, Schema, and Row isolation.
This new project is an independent PostgreSQL implementation with an explicit scope:
catalog-backed database-per-tenant routing, local administrator enrollment, login/logout,
owner-scoped project and task CRUD, optimistic concurrency, pagination, and health probes.
It does not replace the existing backend or claim API/Identity/feature parity with it.

## Decision and alternatives
Keep a separate catalog and a dedicated database/runtime login for each tenant.
The catalog maps opaque tenant IDs to trusted configuration keys; clients never supply URLs.
Two fixtures exercise the boundary. Tenant count is configuration, not a business limit.
One process caps configured targets at 32 to bound connection pools; scale by partitioning
target inventories. Nine production tenants would be inventory data, not a source edit.
Separate roles own migrations; API roles only read catalog and perform tenant DML.
Opaque bearer sessions are hashed in the tenant database and checked on each request.
A session prefix is a selector, never authorization. Catalog membership, active lifecycle,
region, revision, user status, session expiry, and resource ownership are independently checked.
I reject a provider-string replacement of the SQL Server implementation because its RLS,
native types, Identity data, and administrative migrations are database-specific.

## Consequences
Feature modules expose application ports. Domain and use cases do not import Prisma or Nest.
No shared-row/schema compatibility, public enrollment, role-management UI, refresh tokens,
AI provider, durable worker, Redis cache, or existing frontend contract is implied.
Enrollment is a local administrator operation. Resource authorization is project ownership.
Every task mutation uses a transaction and version predicate. Tokens live at most one hour.
The deployment is intentionally single API instance: admission counters are in-process.
Catalog rechecks reject already-stale placement, but cannot fence a relocation racing a write.
Live relocation is unsupported: stop writers, drain transactions, move/validate data,
update catalog revision and runtime inventory, then restart. Never update placement live.

## Migration
This guide creates empty databases only. Existing SQL Server databases are untouched.
An actual cutover requires a separate design for data conversion, API and password parity,
all supported isolation modes, backups, representative upgrades, and differential tests.
Apply future reviewed additive migrations through an administrative release job before
deploying compatible API code. Do not run DDL at API startup or reset a deployed database.

## Rollback
Stop the new API and retain its data. No ingress has been moved from the existing system.
For later releases, roll back only to schema-compatible application images; use a reviewed
forward repair migration for schema failures. Validate restore into a separate database
before any destructive recovery. Local fresh-database tests are not production readiness.
'@
```

## Step 11: Generate private development configuration

```powershell

Write-Source 'scripts/configure-local.mjs' @'

import { existsSync, mkdirSync, writeFileSync } from 'node:fs';

if (existsSync('.env') || existsSync('.local/admin.env')) {

    'Configuration already exists; retain it with the existing database volume.',

}
mkdirSync('.local', { recursive: true });
const secret = () => randomBytes(32).toString('hex');
const administrator = secret();
const catalogPassword = secret();
const passwordA = secret();
const passwordB = secret();
const demoPassword = secret();
const url = (user, password, database) =>
  `postgresql://${user}:${password}@127.0.0.1:55439/${database}?schema=public&connection_limit=4&pool_timeout=5&connect_timeout=5&socket_timeout=10`;
const tenants = [
  {
    id: '11111111-1111-4111-8111-111111111111',
    target: 'alpha',
    database: 'guide_alpha',
    role: 'guide_alpha_api',
    password: passwordA,
  },
  {
    id: '22222222-2222-4222-8222-222222222222',
    target: 'beta',
    database: 'guide_beta',
    role: 'guide_beta_api',
    password: passwordB,
  },
];
const targets = tenants.map((t) => ({
  target: t.target,
  url: url(t.role, t.password, t.database),

const write = (path, value) =>

write('.local/docker.env', `POSTGRES_PASSWORD=${administrator}`);
write(
  '.local/admin.env',
  [
    `CATALOG_DATABASE_URL=${url('postgres', administrator, 'guide_catalog')}`,
    `TENANT_DATABASE_URL=${url('postgres', administrator, 'guide_alpha')}`,
    `ADMIN_TARGETS=${JSON.stringify(tenants.map((t) => ({ ...t, url: url('postgres', administrator, t.database) })))}`,
    `DEMO_PASSWORD=${demoPassword}`,
  ].join('\n'),
);
write(
  '.env',
  [
    'NODE_ENV=development',
    'PORT=3102',
    'HOST=127.0.0.1',
    'TENANT_REGION=local',
    'ALLOWED_ORIGINS=http://localhost:5173',
    `CATALOG_DATABASE_URL=${url('guide_catalog_api', catalogPassword, 'guide_catalog')}`,
    `TENANT_TARGETS=${JSON.stringify(targets)}`,
    `DEMO_PASSWORD=${demoPassword}`,
  ].join('\n'),
);
write(
  '.local/provision.sql',
  [
    '\\set ON_ERROR_STOP on',
    `CREATE ROLE guide_catalog_api LOGIN PASSWORD '${catalogPassword}' NOSUPERUSER NOCREATEDB NOCREATEROLE;`,
    'CREATE DATABASE guide_catalog;',
    ...tenants.flatMap((t) => [
      `CREATE ROLE ${t.role} LOGIN PASSWORD '${t.password}' NOSUPERUSER NOCREATEDB NOCREATEROLE;`,
      `CREATE DATABASE ${t.database};`,
    ]),
    ...['guide_catalog', ...tenants.map((t) => t.database)].map(
      (db) => `REVOKE CONNECT, TEMPORARY ON DATABASE ${db} FROM PUBLIC;`,
    ),
    'GRANT CONNECT ON DATABASE guide_catalog TO guide_catalog_api;',
    ...tenants.map(
      (t) => `GRANT CONNECT ON DATABASE ${t.database} TO ${t.role};`,
    ),
  ].join('\n'),
);
console.log(
  'Private local configuration created; no credentials were printed.',
);
'@
```

The generated files are ignored, not encrypted. Keep them in your private Windows profile; do not share them or include them in transcripts. POSIX mode flags do not replace Windows ACLs. `.env` includes the local fixture password only for the acceptance client; production injects runtime settings through a secret provider and excludes `DEMO_PASSWORD`. Never regenerate credentials against a retained volume.

## Step 19: Build the explicit administrative migration runner

- **Goal**: I apply reviewed migrations serially using administrator URLs without giving the API DDL rights.
- **Command / Action**:

```powershell
New-Item -ItemType Directory -Path 'scripts' -Force | Out-Null
Write-Source 'scripts/migrate.mjs' @'
import { spawnSync } from 'node:child_process';
const targets = JSON.parse(process.env.ADMIN_TARGETS ?? 'null');
if (
  !Array.isArray(targets) ||
  targets.length !== 2 ||
  !process.env.CATALOG_DATABASE_URL
) {
  throw new Error('The local guide administrator environment is required.');
}
const migrate = (schema, env) => {
  const result = spawnSync(
    process.execPath,
    [
      'node_modules/prisma/build/index.js',
      'migrate',
      'deploy',
      '--schema',
      schema,
    ],
    {
      stdio: 'inherit',
      env: { ...process.env, ...env },
    },
  );
  if (result.status !== 0)
    throw new Error(
      'Migration failed; stop rollout and inspect migration status.',
    );
};

## Step 41: Validate configuration before startup

- **Goal**: I reject missing, duplicate, insecure, or unbounded storage configuration at the process boundary.
- **Command / Action**:

```powershell

import { Injectable } from '@nestjs/common';

interface Target {
  readonly target: string;
  readonly url: string;
}
function required(name: string): string {
  const value = process.env[name];
  if (!value || value.trim() !== value) throw new Error(`Invalid ${name}.`);
  return value;
}
function databaseUrl(value: unknown, production: boolean): string {
  if (typeof value !== 'string') throw new Error('Invalid database URL.');
  const url = new URL(value);
  if (
    url.protocol !== 'postgresql:' ||
    !url.username ||
    !url.password ||
    url.pathname === '/'
  )
    throw new Error('Invalid database URL.');
  if (
    production &&
    (url.searchParams.get('sslmode') !== 'require' ||
      url.searchParams.get('sslaccept') !== 'strict')
  )
    throw new Error('Production requires verified database TLS.');
  return value;
}
@Injectable()
export class Settings {
  readonly production: boolean;
  readonly port: number;
  readonly host: string;
  readonly region: string;
  readonly catalogUrl: string;
  readonly targets: readonly Target[];
  readonly origins: readonly string[];
  constructor() {
    const environment = required('NODE_ENV');
    if (!['development', 'test', 'production'].includes(environment))
      throw new Error('Invalid NODE_ENV.');
    this.production = environment === 'production';
    this.port = Number(required('PORT'));
    if (!Number.isInteger(this.port) || this.port < 1 || this.port > 65535)
      throw new Error('Invalid PORT.');
    this.host = required('HOST');

      throw new Error('Invalid bind address.');
    this.region = required('TENANT_REGION');

      required('CATALOG_DATABASE_URL'),
      this.production,
    );
    const parsed: unknown = JSON.parse(required('TENANT_TARGETS'));
    if (!Array.isArray(parsed) || parsed.length < 1 || parsed.length > 32)
      throw new Error('Configure between 1 and 32 targets per process.');
    this.targets = Object.freeze(
      parsed.map((item: unknown): Target => {
        if (
          !item ||
          typeof item !== 'object' ||
          !('target' in item) ||
          !('url' in item) ||
          typeof item.target !== 'string' ||
          !/^[a-z][a-z0-9_-]{0,63}$/.test(item.target)
        )
          throw new Error('Invalid target.');
        return Object.freeze({
          target: item.target,
          url: databaseUrl(item.url, this.production),
        });
      }),
    );
    if (new Set(this.targets.map((t) => t.target)).size !== this.targets.length)
      throw new Error('Duplicate target.');
    const resources = this.targets.map((t) => {
      const u = new URL(t.url);
      return `${u.hostname}:${u.port}${u.pathname}`;
    });
    if (new Set(resources).size !== resources.length)
      throw new Error('Database-per-tenant targets must be distinct.');
    this.origins = Object.freeze(
      required('ALLOWED_ORIGINS')
        .split(',')
        .map((origin) => {
          const url = new URL(origin);
          if (
            url.origin !== origin ||
            !['http:', 'https:'].includes(url.protocol) ||
            (this.production && url.protocol !== 'https:')
          )
            throw new Error('Invalid browser origin.');
          return origin;
        }),
    );

import { randomBytes, scrypt, timingSafeEqual } from 'node:crypto';
function derive(password: string, salt: Buffer): Promise<Buffer> {
  return new Promise((resolve, reject) => {
    scrypt(
      password,
      salt,
      64,
      { N: 32768, r: 8, p: 1, maxmem: 64 * 1024 * 1024 },
      (error, result) => {
        if (error) reject(error);
        else resolve(result);
      },
    );
  });

  const salt = randomBytes(16);
  return `scrypt:${salt.toString('hex')}:${(await derive(password, salt)).toString('hex')}`;

export async function verifyPassword(
  password: string,
  stored: string,
): Promise<boolean> {
  const parts = stored.split(':');
  const salt = parts[1];

  if (
    parts.length !== 3 ||
    parts[0] !== 'scrypt' ||
    !salt ||
    !expected ||
    !/^[a-f0-9]{32}$/.test(salt) ||
    !/^[a-f0-9]{128}$/.test(expected)
  )

  return timingSafeEqual(
    await derive(password, Buffer.from(salt, 'hex')),
    Buffer.from(expected, 'hex'),

}

## Step 44: Implement catalog checks and tenant transactions

- **Goal**: I route only authoritative placements to configured clients and recheck authorization at every operation.
- **Command / Action**:

```powershell
New-Item -ItemType Directory -Path 'src/infrastructure' -Force | Out-Null
Write-Source 'src/infrastructure/database.ts' @'
import { Injectable, type OnModuleDestroy } from '@nestjs/common';
import { PrismaClient as CatalogClient } from '../../generated/catalog/index.js';
import {
  PrismaClient as TenantClient,
  type Prisma,
} from '../../generated/tenant/index.js';
import { Settings } from '../core/settings.js';
import { AppError } from '../domain/errors.js';
import type { TenantContext } from '../domain/models.js';

export type Transaction = Prisma.TransactionClient;
@Injectable()
export class Database implements OnModuleDestroy {
  readonly catalog: CatalogClient;
  private readonly clients = new Map<string, TenantClient>();
  constructor(private readonly settings: Settings) {
    this.catalog = new CatalogClient({
      datasources: { db: { url: settings.catalogUrl } },
    });
    for (const target of settings.targets)
      this.clients.set(
        target.target,
        new TenantClient({ datasources: { db: { url: target.url } } }),
      );
  }
  async placement(tenantId: string) {
    const row = await this.catalog.placement.findUnique({
      where: { id: tenantId },
    });
    if (
      !row ||
      !row.active ||
      row.region !== this.settings.region ||
      !this.clients.has(row.target)
    )
      throw new AppError('forbidden', 'Tenant access denied.');
    return row;
  }
  async member(tenantId: string, userId: string): Promise<void> {
    const membership = await this.catalog.membership.findUnique({
      where: { tenantId_userId: { tenantId, userId } },
    });
    if (!membership?.active)
      throw new AppError('forbidden', 'Tenant access denied.');
  }
  at<T>(target: string, action: (db: Transaction) => Promise<T>): Promise<T> {
    const client = this.clients.get(target);
    if (!client) throw new AppError('forbidden', 'Tenant access denied.');
    return client.$transaction(action, { maxWait: 3000, timeout: 10000 });
  }
  async execute<T>(
    context: TenantContext,
    action: (db: Transaction) => Promise<T>,
  ): Promise<T> {
    const placement = await this.placement(context.tenantId);
    if (
      placement.target !== context.target ||
      placement.revision !== context.revision
    )
      throw new AppError('forbidden', 'Tenant access denied.');
    await this.member(context.tenantId, context.userId);
    return this.at(context.target, async (db) => {
      const session = await db.session.findFirst({
        where: {
          tokenHash: context.tokenHash,
          userId: context.userId,
          expiresAt: { gt: new Date() },
          user: { active: true },
        },
        select: { userId: true },
      });
      if (!session)
        throw new AppError('unauthorized', 'Authentication required.');
      return action(db);
    });
  }
  async ready(): Promise<boolean> {
    try {
      await this.catalog.$queryRaw`SELECT 1`;
      // The configuration cap bounds this probe fan-out and the connection pools.
      await Promise.all(
        [...this.clients.values()].map((db) => db.$queryRaw`SELECT 1`),
      );
      return true;
    } catch {
      return false;
    }
  }
  async onModuleDestroy(): Promise<void> {
    await Promise.all([
      this.catalog.$disconnect(),
      ...[...this.clients.values()].map((db) => db.$disconnect()),
    ]);
  }
}

```

Only this infrastructure class constructs clients. The application receives immutable IDs/revision and ports, never a connection string. No transaction crosses a tenant database. Database-per-tenant isolation is the only supported storage mode in this new project; this does not remove any SQL Server strategy from the existing code. Time checks use UTC instants; tests assert outcomes without timing sleeps.

import { createHash, randomBytes } from 'node:crypto';
import type { IdentityPort } from '../application/ports.js';
import type { TenantContext } from '../domain/models.js';
import { AppError } from '../domain/errors.js';

const digest = (token: string): string =>
  createHash('sha256').update(token).digest('hex');
const dummy = `scrypt:${'0'.repeat(32)}:${'0'.repeat(128)}`;
@Injectable()
export class IdentityAdapter implements IdentityPort {
  constructor(private readonly database: Database) {}
  async login(tenantId: string, email: string, password: string) {
    const placement = await this.database.placement(tenantId);
    const user = await this.database.at(placement.target, (db) =>
      db.user.findUnique({ where: { email } }),
    );
    const valid = await verifyPassword(password, user?.passwordHash ?? dummy);
    if (!valid || !user?.active)
      throw new AppError('unauthorized', 'Invalid credentials.');
    await this.database.member(tenantId, user.id);
    const fresh = await this.database.placement(tenantId);
    if (
      fresh.revision !== placement.revision ||
      fresh.target !== placement.target
    )
      throw new AppError('forbidden', 'Tenant access denied.');
    const accessToken = `${tenantId}.${randomBytes(32).toString('hex')}`;
    const expiresAt = new Date(Date.now() + 60 * 60 * 1000);
    await this.database.at(placement.target, async (db) => {
      // Serialize logins for this account, retaining only one active bearer session.
      await db.$queryRaw`SELECT "id" FROM "User" WHERE "id" = ${user.id}::uuid FOR UPDATE`;
      const current = await db.user.findUnique({ where: { id: user.id } });
      if (!current?.active || current.passwordHash !== user.passwordHash)
        throw new AppError('unauthorized', 'Invalid credentials.');
      await db.session.deleteMany({ where: { userId: user.id } });
      await db.session.create({
        data: { tokenHash: digest(accessToken), userId: user.id, expiresAt },
      });
    });
    return { accessToken, expiresAt: expiresAt.toISOString() };
  }
  async authenticate(tenantId: string, token: string): Promise<TenantContext> {
    if (
      !token.startsWith(`${tenantId}.`) ||
      !/^[a-f0-9-]{36}\.[a-f0-9]{64}$/.test(token)
    )
      throw new AppError('unauthorized', 'Authentication required.');
    const placement = await this.database.placement(tenantId);
    const tokenHash = digest(token);
    const session = await this.database.at(placement.target, (db) =>
      db.session.findFirst({
        where: {
          tokenHash,
          expiresAt: { gt: new Date() },
          user: { active: true },
        },
        select: { userId: true },
      }),
    );
    if (!session)
      throw new AppError('unauthorized', 'Authentication required.');
    await this.database.member(tenantId, session.userId);
    return Object.freeze({
      tenantId,
      target: placement.target,
      revision: placement.revision,
      userId: session.userId,
      tokenHash,
    });
  }
  async logout(context: TenantContext): Promise<void> {
    await this.database.execute(context, async (db) => {
      await db.session.deleteMany({
        where: { tokenHash: context.tokenHash, userId: context.userId },
      });
    });
  }
}

The full token is never persisted, logged, or returned from a project/task endpoint. A new login revokes the previous session for that account in that tenant; logout revokes the presented session immediately. Keep browser tokens in memory and use HTTPS for actual deployments. No cookie-authenticated mutation exists in this design.

import { HttpException, Injectable } from '@nestjs/common';
@Injectable()
export class Admission {
  private readonly counters = new Map<
    string,
    { count: number; until: number }
  >();
  private activeLogins = 0;
  check(key: string, limit: number): void {
    const now = Date.now();
    for (const [entry, value] of this.counters)
      if (value.until <= now) this.counters.delete(entry);
    let counter = this.counters.get(key);
    if (!counter) {
      if (this.counters.size >= 10000)
        throw new HttpException('Request capacity reached.', 429);
      counter = { count: 0, until: now + 60000 };
      this.counters.set(key, counter);
    }
    counter.count += 1;
    if (counter.count > limit)
      throw new HttpException('Rate limit reached.', 429);
  }
  async login<T>(operation: () => Promise<T>): Promise<T> {
    if (this.activeLogins >= 4)
      throw new HttpException('Login capacity reached.', 429);
    this.activeLogins += 1;
    try {
      return await operation();
    } finally {
      this.activeLogins -= 1;
    }
  }
}

Limits are 120 requests/IP/minute, 10 login attempts/IP/minute and 100 protected requests/tenant/user/minute. Counters expire, are capped, and cannot create an unbounded allocation. These limits and the four-hash concurrency cap are initial local values, not measured production capacity. Multi-replica deployment requires shared admission at trusted ingress or a tested shared store.

import {
  ArgumentsHost,
  Catch,
  HttpException,
  Logger,
  type ExceptionFilter,
} from '@nestjs/common';
import type { FastifyReply, FastifyRequest } from 'fastify';
import { AppError } from '../domain/errors.js';
@Catch()
export class ErrorFilter implements ExceptionFilter {
  private readonly logger = new Logger('HttpFailure');
  catch(error: unknown, host: ArgumentsHost): void {
    const reply = host.switchToHttp().getResponse<FastifyReply>();
    const request = host.switchToHttp().getRequest<FastifyRequest>();
    let status = 503;
    let message = 'Service temporarily unavailable.';
    if (error instanceof AppError) {
      status = {
        invalid: 400,
        unauthorized: 401,
        forbidden: 403,
        missing: 404,
        conflict: 409,
      }[error.code];
      message = error.message;
    } else if (error instanceof HttpException) {
      status = error.getStatus();
      message = status === 429 ? 'Rate limit reached.' : 'Request rejected.';
    } else if (
      error &&
      typeof error === 'object' &&
      'code' in error &&
      typeof error.code === 'string' &&
      ['P2002', 'P2003', 'P2025', 'P2034'].includes(error.code)
    ) {
      status = 409;
      message = 'The resource changed; reload and retry.';
    } else {
      this.logger.error(
        JSON.stringify({ event: 'request_failed', requestId: request.id }),
      );
    }
    if (status === 429) reply.header('Retry-After', '60');
    void reply
      .code(status)
      .send({ statusCode: status, message, requestId: request.id });
  }
}

## Step 62: Configure the HTTP pipeline

- **Goal**: I enforce body limits, browser origins, security headers, admission, and redacted failures before listening.
- **Command / Action**:

```powershell
New-Item -ItemType Directory -Path 'src' -Force | Out-Null
Write-Source 'src/bootstrap.ts' @'
import 'reflect-metadata';
import { randomUUID } from 'node:crypto';
import { NestFactory } from '@nestjs/core';
import { LogController } from 'fastify';
import {
  FastifyAdapter,
  type NestFastifyApplication,
} from '@nestjs/platform-fastify';
import { AppModule } from './app.module.js';
import { Settings } from './core/settings.js';
import { Admission } from './http/admission.js';
import { ErrorFilter } from './http/error.filter.js';

export async function createApplication(): Promise<NestFastifyApplication> {
  const adapter = new FastifyAdapter({
    bodyLimit: 16384,
    trustProxy: false,
    requestTimeout: 30000,
    genReqId: () => randomUUID(),
    logController: new LogController({ disableRequestLogging: true }),
    logger: {
      redact: [
        'req.headers.authorization',
        'req.headers.cookie',
        'res.headers.set-cookie',
      ],
    },
  });
  const app = await NestFactory.create<NestFastifyApplication>(
    AppModule,
    adapter,
    { logger: false, abortOnError: false },
  );
  const settings = app.get(Settings);
  const admission = app.get(Admission);
  const server = adapter.getInstance();
  server.addHook('onRequest', async (request, reply) => {
    reply.header('X-Request-ID', request.id);
    reply.header('X-Content-Type-Options', 'nosniff');
    reply.header('X-Frame-Options', 'DENY');
    reply.header('Cache-Control', 'no-store');
    reply.header(
      'Content-Security-Policy',
      "default-src 'none'; frame-ancestors 'none'",
    );
    const origin = request.headers.origin;
    if (origin) {
      if (!settings.origins.includes(origin)) {
        await reply.code(403).send({ message: 'Origin denied.' });
        return;
      }
      reply.header('Vary', 'Origin');
      reply.header('Access-Control-Allow-Origin', origin);
      reply.header(
        'Access-Control-Allow-Methods',
        'GET,POST,PUT,DELETE,OPTIONS',
      );
      reply.header(
        'Access-Control-Allow-Headers',
        'Authorization,Content-Type,X-Tenant-ID',
      );
    }
    if (
      request.url !== '/alive' &&
      request.url !== '/ready' &&
      request.url !== '/health'
    ) {
      try {
        admission.check(`ip:${request.ip}`, 120);
      } catch {
        await reply
          .header('Retry-After', '60')
          .code(429)
          .send({ message: 'Rate limit reached.' });
        return;
      }
    }
    if (request.method === 'OPTIONS') await reply.code(204).send();
  });
  server.addHook('onResponse', async (request, reply) => {
    request.log.info(
      {
        requestId: request.id,
        method: request.method,
        statusCode: reply.statusCode,
        elapsedMs: reply.elapsedTime,
      },
      'request_complete',
    );
  });
  app.useGlobalFilters(new ErrorFilter());
  app.enableShutdownHooks();
  return app;
}
'@
```

Fastify requestTimeout bounds request receipt, not arbitrary business execution. PostgreSQL statement/lock limits and Prisma transaction limits bound database work separately. HTTP disconnects do not automatically cancel Prisma queries. Requests carry no mutable global tenant state. Database outages return redacted failures; the API never falls back to a default database.

Node 24+, NestJS/Fastify, Prisma 6, PostgreSQL 17. This project is separate from the

HTTP controllers parse unknown input and call focused application handlers.

The angle-bracket text describes a runtime value, not a source-code placeholder.

| --- | --- | --- | --- |
| GET | /alive | none | 200 process liveness |
